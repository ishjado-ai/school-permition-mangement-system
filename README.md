CASE STUDY: COLLEGE BAPTIST DE NGARAMA
    1.INTRODUCTION   
    a school permission management system 
    is web-based application designed to help school manage
    student permission efficiently. instead of using paper notes 
    student can request permission online and administrators

     This system improve communication between student, teacher
     and administration while reducing time waste and error in 
      manual processing.

2.OBJECTIVE OF THE SYSTEM

	to digitalize student permission request.
	to allow student to request   permission online.
	  to allow admin or teacher to approve or reject request.
	to keep record of all permission.
	to improve efficiency in school management.

 3.PROBLEM IDENTIFICATION
 	In many school permission requests are handle manually
 	Using paper form or verbal communication this method is slow sometime
	Confusing, and can lead to lost or delayed permission approvals.it is also
                  Difficult to store and track record properly.
4. PROPOSED SOLUTION       
                  The proposed solution:
                   Is school permission management system, a digital system that allow student
                   To request permission online and enable teacher or administrator to approval 
                      request                                         
                    Quickly and efficient and manage history or record.

5.SYSTEM USER (actor)
           STUDENT-submit permission request. 
           TEACHER-review request.
           SCHOOL ADMINISTATION-manage system and give final approval.
            PARENT: can be notified about permission.

6.SYSTEM REQUIREMENT
•	FUNCTIONAL REQUIREMENT
                                                                                                
	Student can login and submit permission request
	Teacher can view approve or reject request.
	Administration can manage user and record
	System store all permission history.
	Notification are sent for update
•	NON-FUNCTION REQUIREMENT

	The system must be secure (login required)
	it must be faster and easy to use.
	it should work on computer or mobile.
	data must be store safely and accurately
   
          
 7.SYSTEM PROCESS (how it work)
1.	Student login into the system.
2.	Student submit permission request.
3.	Teacher receive and view request.
4.	Teacher or admin approves or reject.
5.	The student is notified of the decision.
6.	System store the record for future use.

8.ADVANTAGES OF THE SYSTEM

	Reduce paper work.
	Saves time for teacher and student.
	Improve communication.
	Keep proper record.
	Reduces error in permission handling.
